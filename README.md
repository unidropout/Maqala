# Maqala

Maqala (каз. «мақала», «статья») — сайт для поиска научных статей в открытом доступе с акцентом на работы Казахстана. Собирает метаданные из открытых источников (в MVP — OpenAlex), приводит их к единому формату и показывает с поиском и фильтрами. Полные тексты не хранятся: у каждой статьи есть ссылка на оригинал.

Статус: этап 0, подготовка.

## Локальный запуск

Нужен [Docker](https://docs.docker.com/get-docker/) с Docker Compose.

1. Создай файл с настройками и задай в нём свой пароль `POSTGRES_PASSWORD` (и такой же в `DATABASE_URL`):

   ```bash
   cp .env.example .env
   ```

2. Запусти базу:

   ```bash
   docker compose up -d
   ```

3. Проверь, что база работает:

   ```bash
   docker compose exec db psql -U maqala -d maqala -c "select version();"
   ```

Остановить базу: `docker compose down`. Удалить базу вместе с данными: `docker compose down -v`.
