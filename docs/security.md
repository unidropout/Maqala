## Аккаунты и админка (добавлены 2026-11-05)

- Пароли: scrypt, соль 16 байт, сравнение за постоянное время; для неизвестной почты тоже считается хеш, чтобы по времени ответа нельзя было узнать, есть ли аккаунт.
- Ограничение попыток: вход, регистрация и смена пароля — не больше 20 за 15 минут с IP и 10 на одну почту.
- Сессии: токен 32 байта в `httpOnly`-cookie, в базе только хеш; при смене пароля завершаются остальные сессии, при блокировке — все.
- CSRF: формы — server actions Next.js (проверка Origin встроена), cookie `SameSite=Lax`; вход через Google защищён `state` и PKCE.
- Права проверяются на сервере в каждом действии; суперадмин не может снять роль с себя или заблокировать себя.
- Захват аккаунта через Google: если аккаунт с той же почтой создан с паролем без подтверждения почты, пароль при входе через Google сбрасывается.
- Открыто: подтверждение почты и восстановление пароля (нужен сервис писем), политика конфиденциальности, 2FA для суперадминов.

Проверено и в порядке: каждое серверное действие и каждая страница админки заново проверяют вход и роль на сервере; роли и блокировка читаются из базы при каждом запросе, поэтому снятие роли действует сразу; скрытые статьи не отдаются ни страницами, ни API, ни избранным; ссылки статей из админки — только `http(s)`; подделка запроса (CSRF) закрыта проверкой Origin в server actions и `SameSite=Lax`; вход через Google — `state` и PKCE, cookie с `state` недоступен скриптам; в коде нет отладочных лазеек и тестовых паролей, `.env` не в git.

## Проверено и в порядке

- **Секреты.** `.env` в `.gitignore` и ни разу не попадал в историю git; паролей, токенов и личных почт в коде и истории нет; коммиты подписаны noreply-адресом GitHub. Репозиторий можно делать публичным.
- **SQL.** Все запросы параметризованы. В текст запроса подставляются только номера параметров, постоянные фрагменты и проверенное число страницы (`web/lib/works.ts`); коннектор пишет через `psycopg` с параметрами.
- **Входные данные API.** Год — только 4 цифры, страна — 2 буквы, страница — целое 1–500, запрос — до 200 символов, id — положительное целое; ошибки возвращаются как JSON без подробностей.
- **HTML.** Пользовательские данные выводятся только через React (экранирование). Единственный `dangerouslySetInnerHTML` — постоянный скрипт темы без внешних данных.
- **Авторизация, загрузка файлов, платежи** — в MVP их нет, атаковать нечего.
- **Ключ OpenAlex** передаётся в заголовке `Authorization`, а не в адресе, поэтому не попадает в логи и сообщения об ошибках.
