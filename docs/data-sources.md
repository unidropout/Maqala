# Источники данных

Перед подключением каждого источника здесь фиксируются его лицензия, условия и особенности данных (ТЗ §6.1, §10).

## OpenAlex

**Статус:** подключён (MVP), коннектор `ingest/openalex/`.
**Сайт:** https://openalex.org, документация: https://help.openalex.org
**Проверено:** 2026-11-01

### Лицензия данных

Данные OpenAlex распространяются под **CC0** (общественное достояние): их можно хранить, обрабатывать и показывать без договора и без обязательной атрибуции. Мы всё равно указываем OpenAlex как источник у каждой статьи и на странице «О проекте» (ТЗ §10).

Платными бывают не данные, а нагрузка на API.

### Условия доступа к API

| Режим | Дневной бюджет | Ограничения |
|---|---|---|
| Без ключа | $0.10 на всех пользователей одного IP | только обычные страницы: не дальше первых 10 000 результатов, cursor-страницы недоступны |
| Бесплатный ключ | $1 на аккаунт | cursor-страницы, любое число результатов |

Стоимость операций:
- список с фильтром (наш основной запрос): $0.10 за 1000 запросов, то есть $0.0001 за страницу из 100 статей;
- получение одной записи по id: бесплатно;
- полнотекстовый поиск в OpenAlex: $1 за 1000 запросов (мы им не пользуемся).

Бюджет сбрасывается в полночь по UTC. Все 109 тысяч открытых статей Казахстана — это около 1100 страниц, примерно $0.11: с бесплатным ключом укладывается в один день.

**Ключ:** зарегистрироваться на https://openalex.org/signup, взять ключ на https://openalex.org/settings/api-key и записать в `.env` как `OPENALEX_API_KEY`. Ключ секретный, в git не попадает.

### Что берём

Запрос: `/works` с фильтром `is_oa:true, is_retracted:false, is_paratext:false` плюс условия выборки и `select` только нужных полей (список в `ingest/openalex/client.py`).

Выборки (проверено 2026-11-03, только открытый доступ):

| Условие | Статей |
|---|---|
| авторы из Казахстана (`authorships.countries:KZ`) | ~109 000 |
| язык казахский (`language:kk`) | ~15 900 |
| язык русский и авторы из Казахстана | ~13 400 |
| журналы Казахстана (`primary_location.source.country_code:KZ`) | ~79 000, из них русских ~17 500 |

Статьи казахстанских журналов часто не связаны с казахстанскими организациями в OpenAlex, поэтому выборка по журналам находит то, чего нет в выборке по авторам.

### Особенности данных

- **Авторы в списках обрезаны до 100.** У крупных международных статей (до нескольких тысяч авторов) казахстанский автор может оказаться дальше сотого. Коннектор дозапрашивает такие статьи по id: это бесплатно.
- **Аннотация** приходит как инвертированный индекс `{слово: [позиции]}`, коннектор собирает её в текст. Примерно у 12% статей аннотации нет.
- **Язык** определяется автоматически и часто ошибается: в выборке из 200 статей с меткой `kk` 24 оказались английскими, среди статей с меткой `ru` и казахстанскими авторами примерно 15% казахских и 22% английских; встречаются явно неверные `lv`, `et`. Поэтому коннектор уточняет язык по названию (решение 008). После загрузки (2026-11-03): 13 399 казахских, 19 468 русских, 6 543 английских статей.
- **Лицензия** указана примерно у 78% открытых статей; у остальных показываем «лицензия не указана».
- **`pdf_url`** иногда ведёт не на PDF (встречалась картинка), поэтому ссылкой на бесплатный текст берём страницу лучшей открытой версии.
- **DOI** есть почти у всех (99,8% в первой выборке).
- В заголовках бывают HTML-теги (`<i>`, `<sub>`) и HTML-сущности: коннектор их убирает.
