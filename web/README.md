# web

Сайт и API на Next.js 15 + TypeScript + Tailwind CSS (ТЗ §7). Данные берутся из PostgreSQL, строка подключения — `DATABASE_URL` из общего `.env` в корне репозитория.

## Запуск

База должна быть запущена и заполнена (см. [ingest/README.md](../ingest/README.md)).

```bash
cd web
npm install
npm run dev
```

Сайт откроется на http://localhost:3000.

## Страницы

| Адрес | Что это |
|---|---|
| `/` | главная: поиск, статистика, Казахстан, самые цитируемые |
| `/search` | выдача: поиск, фильтры с количеством, сортировка, страницы |
| `/works/{id}` | статья |
| `/countries/{code}` | страница страны, например `/countries/kz` |
| `/about` | о проекте |

## API

| Метод | Путь | Что возвращает |
|---|---|---|
| GET | `/api/works` | поиск: `q`, `country` (можно несколько), `year_from`, `year_to`, `field`, `language`, `license` (`none` — без лицензии), `sort` (`relevance`, `date`, `cited`), `page` |
| GET | `/api/works/{id}` | одна статья |
| GET | `/api/facets` | значения фильтров с количеством (те же параметры, что у поиска) |
| GET | `/api/countries` | страны и количество статей |
| GET | `/api/countries/{code}` | статистика страны |

Ошибки: `{"error": {"code": "...", "message": "..."}}` с кодами 400, 404, 500.

## Устройство

- `lib/works.ts` — все запросы к базе (параметризованные), разбор фильтров из URL.
- `lib/i18n.ts` — все строки интерфейса; казахский и английский добавятся отдельными словарями.
- `app/globals.css` — черновые токены цветов для светлой и тёмной темы (полная дизайн-система — этап 4).
